# Guides

`ruststream-lapin` is the RabbitMQ broker for [RustStream](https://powersemmi.github.io/ruststream/latest/),
built on [lapin](https://docs.rs/lapin), the AMQP 0.9.1 client. The guides show how to build a
RabbitMQ service with it.
Start with [Getting started](getting-started.md).
